# Web Development Summer 2026 Internship

**Location:** Remote (Global)  
**Time Commitment:** ~20 hours/week, 8-9 months  
**Type:** Unpaid Internship  

## Position Overview

We are seeking a highly motivated, self-directed **Web Development Intern** to join our technical team. This role will focus on enhancing our digital presence and developing web-based tools that facilitate research collaboration and public education.

## Key Responsibilities

- Design, develop, and maintain responsive web applications and foundation websites
- Implement interactive features to visualize complex neuroscience data and research findings
- Optimize web platforms for maximum speed, scalability, and accessibility
- Integrate backend services and APIs to support community engagement and data sharing
- Contribute to frontend and backend development based on evolving project needs
- Document code and maintain high-quality technical documentation
- Collaborate with researchers and technical volunteers to align on goals and implementation
- Participate in code reviews and assist with testing

## Qualifications

- Currently pursuing a degree in Computer Science, Software Engineering, Web Development, or a related field
- Strong proficiency in HTML, CSS, and JavaScript; experience with modern frameworks (React, Vue, or Angular)
- Experience working with version control tools such as Git
- Demonstrated ability to build, test, and deploy functional web applications
- Understanding of UI/UX principles and comfort working in a collaborative design environment
- Excellent communication skills for presenting technical concepts to both technical and non-technical audiences
- Strong problem-solving skills and attention to detail
- Ability to work independently with minimal supervision
- Interest in neuroscience, brain-machine interfaces, or whole brain emulation is highly desirable
- **Preferred:** Experience with backend technologies (Node.js, Python/Django), CMS management, or data visualization libraries like D3.js
